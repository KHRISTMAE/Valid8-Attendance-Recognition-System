# 📸 Facial Recognition Attendance System (Valid8)

This project is a **Facial Recognition Attendance System** designed for school events, built with **FastAPI**, **PostgreSQL**, and a lightweight **HTML/CSS/JavaScript frontend**. The system is fully containerized using **Docker** for easy deployment and management in local environments.

## 📦 About This Project

- Allows event organizers to manage attendance using facial recognition technology.
- Supports multiple user roles including **Admin**, **Student**, **SSG Officers**, and **Event Organizers**.
- Uses **Docker Compose** to quickly build and run all necessary services.
